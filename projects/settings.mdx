## General

Change the project name, production branch, build command, and root directory. Renaming a project does **not** change its slug or `*.orbit.app` hostname; those are fixed at creation.

## Deployment protection

| Setting | Effect |
| --- | --- |
| **Password protect previews** | Visitors must enter a shared password to view preview deployments |
| **Require Orbit login** | Only organization members can view previews |
| **Auto-cancel superseded builds** | When a newer commit lands on the same branch, queued builds for older commits are canceled |
| **Skew protection** | Old client assets stay available for 24 hours after a deployment so in-flight sessions don't break |

## Danger zone

The danger zone holds two actions that can't be undone.

### Transfer project

Moves the project, its deployments, domains, and variables to another organization. The receiving organization's owner must accept the transfer.

### Delete project

Deleting a project removes every deployment, domain, environment variable, and log line for it. Custom domains are released immediately and can be claimed by another project.

To delete, click **Delete project** and type the project slug exactly as shown. The confirm button stays disabled until the text matches.

<Warning>
Only **Owners** and **Admins** can delete projects. There is no recovery period; export anything you need first.
</Warning>
